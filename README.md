# DeskBuddy

App leve para Windows que organiza o seu dia com a companhia do **Mochi**: missões, hábitos,
foco, lembretes e notas, tudo no seu computador. Sem conta, sem nuvem e sem anúncios.

- **Site:** https://mateozord.github.io/DeskBuddy/
- **Baixar:** [DeskBuddy-setup.exe](https://github.com/mateozord/DeskBuddy/releases/latest/download/DeskBuddy-setup.exe) (Windows 10 e 11)
- **Versões e novidades:** [Releases](https://github.com/mateozord/DeskBuddy/releases)

Este repositório só guarda os instaladores e o site. O código-fonte do DeskBuddy é privado.
